# 等连串

一件事每次发生的概率是 p，每次相互独立。试 n 次，至少碰到一次「连续 k 次都发生」的可能性有多大？平均要等多少次？要五成 / 九成 / 九十九成把握得试多少次？

- 两种问法：指定那个结果连续 k 次（硬币正面、骰子六点、投中），或 m 种等可能结果里随便哪个连续 k 次（π 里同一个数字连着出现）。
- 逐次精确递推；1 − P 极小时用生成函数主极点；超过 200 万次的把握次数按尾部外推，页面标「约」。
- 附 π 小数点后前 100 万位（本页用 Chudnovsky 公式自己算出）里真实出现的连串，对照模型。
- 默认例子是虚构的。不是投注建议：连续输了之后，下一次赢的概率不会变大。

纯静态页面，打开 `index.html` 即可。核心测试：`node --test tests/core.test.cjs`。
